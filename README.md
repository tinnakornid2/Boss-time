# ⚔️ Lineage 2 Boss Tracker (#Kain7 Edition)

ระบบติดตามเวลาเกิดบอสและอีเวนต์แคลนแบบเรียลไทม์ (Real-Time Boss & Event Spawn Tracker) สำหรับเกม Lineage 2 ถอดแบบโครงสร้างลอจิกและฟีเจอร์ทั้งหมดจาก `boss.kain7.com`

---

## 🌟 ฟีเจอร์หลัก (Features)

1. **ฐานข้อมูลบอสครบถ้วน (89 บอส + 3 อีเวนต์)**:
   - บอสทั่วไป และบอสบุกรุก (Invasion ⚡)
   - ข้อมูลรอบเกิด (Interval), โอกาสเกิด (Chance %), และสถานที่เกิด (Location)
2. **ระบบนับเวลาเรียลไทม์ (Real-Time Synchronization)**:
   - ซิงค์ข้อมูลระหว่างสมาชิกในกิลด์ทุกคนพร้อมกันทันทีผ่าน WebSockets
   - แสดงตัวนับเวลาถอยหลัง (Countdown) สลับกับเวลาเกิดจริงได้
   - นาฬิกาเวลาเซิร์ฟเวอร์ และเวลาเครื่องผู้ใช้
3. **การจำแนกสถานะบอส**:
   - **Just Spawned / ALIVE**: บอสที่เพิ่งเกิดใน 5 นาที หรือบอสที่ถูกปักหมุดว่ามีตัว (Pinned Alive) พร้อมแถบสีเขียวนีออนกระพริบ
   - **Upcoming Bosses**: จัดเรียงตามบอสที่ใกล้จะเกิดที่สุดขึ้นก่อน
   - **Advance (ข้ามรอบ)**: บันทึกการข้ามรอบสำหรับบอสโอกาสเกิด 50% ที่ไม่เกิด
4. **Server Maintenance Manager (ระบบคำนวณเวลาหลังเปิดเซิร์ฟ)**:
   - ใส่เวลาเปิดเซิร์ฟเวอร์ แล้วกด **"Apply Reset Boss Time"**
   - คำนวณเวลาเกิดใหม่ของบอสทั้ง 73 ตัวทันทีตาม `resetTimeConfigs` (เช่น Andras +11h 20m, Queen Ant +5h 25m เป็นต้น)
   - สามารถแก้ไขและบันทึกเวลา Offset ของแต่ละบอสได้เอง
5. **ระบบเสียงแจ้งเตือน (Sound Alert Engine)**:
   - รวมไฟล์เสียงแท้จากเกม 22 เสียง (alert, warHorn, bell, just-spawned, game levelup ฯลฯ)
   - ตั้งเตือนล่วงหน้าได้ (1 นาที, 3 นาที, 5 นาที, 10 นาที)
   - มีตัวปรับระดับเสียง (Volume Slider) และปุ่มทดสอบเสียง
   - มีปุ่ม Mute ปิดเสียงเฉพาะบอสบางตัวได้
6. **ป้ายประกาศแคลน (Announcement Banner)**:
   - แถบประกาศข้อความด้านบนสุดสำหรับหัวแคลนแจ้งเตือนสมาชิก
7. **Overlay สำหรับสตรีมเมอร์ (Streamer OBS Overlay)**:
   - ปรับความโปร่งใส (Opacity Slider 30% - 100%) เพื่อนำไปใช้เป็น Browser Source ใน OBS ได้อย่างสวยงาม
8. **API สำหรับ Discord Bot**:
   - `GET /api/v1/time-bosses`: ดึงข้อมูลบอสและเวลาเกิดทั้งหมดเป็น JSON สำหรับเขียนบอท Discord
