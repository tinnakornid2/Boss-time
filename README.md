# ⚔️ Lineage 2 Boss Tracker (#Kain7 Edition) `v1.3.14`

ระบบติดตามเวลาเกิดบอสและอีเวนต์แคลนแบบเรียลไทม์ (Real-Time Boss & Event Spawn Tracker) สำหรับเกม Lineage 2 ถอดแบบโครงสร้างลอจิกและฟีเจอร์ทั้งหมดจาก `boss.kain7.com`

---

## 🌟 ฟีเจอร์หลัก (Features)

1. **ฐานข้อมูลบอสครบถ้วน (89 บอส + 3 อีเวนต์)**:
   - บอสทั่วไป และบอสบุกรุก (Invasion ⚡)
   - ข้อมูลรอบเกิด (Interval), โอกาสเกิด (Chance %), และสถานที่เกิด (Location)
2. **ระบบนับเวลาเรียลไทม์ (Real-Time Synchronization)**:
   - ซิงค์ข้อมูลระหว่างสมาชิกทุกหน้าจอผ่าน Firebase RTDB และ polling สำรอง
   - แสดงตัวนับเวลาถอยหลัง (Countdown) สลับกับเวลาเกิดจริงได้
   - นาฬิกาเวลาเซิร์ฟเวอร์ และเวลาเครื่องผู้ใช้
3. **การจำแนกสถานะบอส**:
   - **NOW**: แสดงบนสุดเป็นเวลา 10 นาที หรือค้างไว้เมื่อกด Still Alive
   - หากไม่มีเวลาตายใหม่หลังครบ 10 นาที ระบบใช้เวลาเกิดล่าสุดคำนวณรอบถัดไป
   - **Upcoming Bosses**: จัดเรียงตามบอสที่ใกล้จะเกิดที่สุดขึ้นก่อน
   - **Advance (ข้ามรอบ)**: บันทึกการข้ามรอบสำหรับบอสโอกาสเกิด 50% ที่ไม่เกิด
4. **Server Maintenance Manager (ระบบคำนวณเวลาหลังเปิดเซิร์ฟ)**:
   - ใส่เวลาเปิดเซิร์ฟเวอร์ แล้วกด **"Apply Reset Boss Time"**
   - คำนวณเวลาเกิดใหม่ของบอสทั้ง 73 ตัวทันทีตาม `resetTimeConfigs` (เช่น Andras +11h 20m, Queen Ant +5h 25m เป็นต้น)
   - สามารถแก้ไขและบันทึกเวลา Offset ของแต่ละบอสได้เอง
5. **ระบบเสียงแจ้งเตือน (Sound Alert Engine)**:
   - รวมไฟล์เสียงแท้จากเกม 22 เสียง (alert, warHorn, bell, just-spawned, game levelup ฯลฯ)
   - ตั้งเตือนล่วงหน้าได้ (1 นาที, 3 นาที, 5 นาที, 10 นาที)
   - มีตัวปรับระดับเสียง (Volume Slider) และปุ่มทดสอบเสียง
   - มีปุ่ม Mute ปิดเสียงเฉพาะบอสบางตัวได้
6. **ป้ายประกาศแคลน (Announcement Banner)**:
   - แถบประกาศข้อความด้านบนสุดสำหรับหัวแคลนแจ้งเตือนสมาชิก
7. **Overlay สำหรับสตรีมเมอร์ (Streamer OBS Overlay)**:
   - ปรับความโปร่งใส (Opacity Slider 30% - 100%) เพื่อนำไปใช้เป็น Browser Source ใน OBS ได้อย่างสวยงาม
8. **ระบบคลาวด์ Firebase Realtime Database (RTDB)**:
   - รองรับการเชื่อมต่อกับ Firebase (`boss-timel2m`) ซิงค์เวลาบอสขึ้นคลาวด์อัตโนมัติ
   - รองรับการ Deploy บน Vercel Serverless อย่างสมบูรณ์แบบ
9. **ระบบสำรองข้อมูล (Backup Engine)**:
   - สำรองข้อมูลด้วยไฟล์ `backup.bat` หรือคำสั่ง `npm run backup`
   - ดาวน์โหลด Backup JSON ผ่าน API: `GET /api/v1/backup`
10. **API สำหรับ Discord Bot**:
   - `GET /api/v1/time-bosses`: ดึงข้อมูลบอสและเวลาเกิดทั้งหมดเป็น JSON สำหรับเขียนบอท Discord

## 🔐 การเข้าสู่ระบบและสิทธิ์

### 1. ผู้ดูแลระบบ (Admin)
- **สิทธิ์การใช้งาน**: บันทึกเวลา, Unset, Still Alive, เพิ่ม/ลบบอส, รีเซ็ต, จัดการ Event และส่งแจ้งเตือนสมาชิก

### 2. สมาชิกในแคลน (Member)
- **สิทธิ์การใช้งาน**: ดูข้อมูลและรับการแจ้งเตือนเท่านั้น ห้ามแก้เวลาและห้ามส่งแจ้งเตือนด้วยการดับเบิลคลิก
- **การตั้งค่าส่วนตัว**: เพิ่ม–ลดเสียง, ปิดเสียง, เลือกเสียงแจ้งเตือน และปรับ Display/Audio ของเครื่องตัวเองได้ทั้งหมด โดยไม่กระทบเครื่องอื่น

รหัสผ่านจริงจัดการผ่านระบบและเก็บเป็น scrypt hash ห้ามเขียนรหัสผ่านลงใน repository

ปุ่มระบบบนแถบด้านซ้ายแสดงเป็นไอคอนขนาดเล็ก: รหัสผ่าน (Admin เท่านั้น), Firebase, เวอร์ชัน และสถานะเสียง Realtime/Polling โดยชี้เมาส์เพื่อดูคำอธิบายอังกฤษ–ไทย

## 🚀 วิธีเปิดใช้งานระบบ (Quick Start)

### วิธีที่ 1: ดับเบิลคลิกไฟล์ `run.bat`
เพียงดับเบิลคลิกที่ไฟล์ [run.bat](file:///c:/Users/tinna/Downloads/Boss%20time/run.bat) ระบบจะเริ่มทำงานทันที

### วิธีที่ 2: รันผ่าน Terminal / Command Line
```bash
npm start
```

จากนั้นเปิดเว็บเบราว์เซอร์แล้วเข้าใช้งานที่:
👉 **[http://localhost:3000](http://localhost:3000)**
